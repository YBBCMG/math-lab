# 秒懂数学 · MathLab

把每一道题拆成「一步一个动作」的动画讲解。纯静态，双击 `index.html` 就能看，也能直接丢到任何静态托管上。

**线上地址：<https://ybbcmg.github.io/math-lab/>** —— 手机、电脑、教室投屏都能直接开，改完推上去约 1 分钟自动生效。

## 三档：演示 / 证明 / 推论

**这是全站最重要的一条规矩。**「看起来对」和「证得对」是两件事，混在一起教等于骗人。

| 档 | 含义 | 判据 |
|---|---|---|
| 〔演示〕 | 只能建立直觉，**不是证明** | 靠眼睛、靠量、靠拼；没有引用任何定理 |
| 〔证明〕 | 从已知条件和已证定理推出结论 | 每一步都写得出「依据」 |
| 〔推论〕 | 依赖前面某个已证结论 | 必须标 `needs`，界面会提示「必须先看方法 N」 |

注册时给方法加 `tier`：

```js
methods: [
  { name: '撕角拼平角', tier: 'demo',      sub: '直观演示 · 看着像，还不是证明', steps: m1 },
  { name: '作平行线看内错角', tier: 'proof', sub: '严格证明 · 只用了平行线性质', steps: m2 },
  { name: '外角定理', tier: 'corollary',   sub: '推论 · 前提：外角定理已成立',
    needsMsg: '外角定理本身也是用平行线证出来的……', steps: m3 }
]
```

**顺序不能乱**：演示 → 猜想 → 证明 → 推论。把「特殊位置法」摆在「面积法」前面，就是循环论证。

## 配音

每一步都有中文配音（edge-tts，zh-CN-XiaoxiaoNeural）。文字来源就是讲稿里的 `say` + `依据是，{cite}` + `why`，**不另抄一份**，所以改文案必然同步改配音。

```bash
python tools/tts.py        # 读 tools/narration.json → media/<id>/<mi>-<si>.mp3
node tools/dump.mjs        # 改完讲稿先跑这个，从真实页面重新导出 89 条文本
```

播放器行为：
- 手动翻页也会朗读当前步
- 「自动播放」由配音驱动节奏：一条播完自动进下一步（没有配音就回落到定时器）
- 速度档同时改 `playbackRate`，2× 就是语速加倍
- 配音开关默认开，存在 localStorage


## 每天加一道题

**只需要新建一个文件**，然后在 `js/lessons/manifest.js` 里登记文件名。

```js
// js/lessons/xxx.js
(function () {
  window.MATHLAB_LESSONS = window.MATHLAB_LESSONS || [];
  window.MATHLAB_LESSONS.push({
    id: 'your-id',                 // URL 里的 ?id=
    title: '题目标题',
    grade: '初二',
    topic: '几何 · 面积',
    tags: ['几何', '面积'],         // 首页筛选用
    question: '题目原文',
    methods: [
      { name: '解法一', sub: '一句话说明', steps: [ /* ... */ ] }
    ]
  });
})();
```

## 一步（step）怎么写

```js
{
  say:  '这一步做什么（必填，一句话，只说一件事）',
  cite: '这一步引用的定理（证明档必填，界面上单独显示成「依据」徽章，也会被读出来）',
  why:  '为什么能这么做（补充说明：条件、边界、容易踩的误解）',
  eq:   '这一步在算什么（可选，会显示在右侧公式卡里）',
  hold: 2000,        // 可选，自动播放时这一步停留多久（毫秒）
  add:  [元素...],   // 新出现的
  upd:  [{ id, ... }], // 改已有的（可触发动画）
  del:  ['id'],      // 淡出删除
  delNow: ['id']     // 瞬切删除（整张图换图时用，避免新旧叠加糊成一团）
}
```

### 元素类型

| k | 参数 | 说明 |
|---|---|---|
| `poly` | `pts:[[x,y],...]` | 多边形 |
| `line` | `a:[x,y], b:[x,y]` | 线段，可 `dash:[8,6]` |
| `circ` | `c:[x,y], r` | 圆点 |
| `rect` | `x,y,w,h` | 矩形 |
| `sector` | `c:[x,y], r, from, to` | 扇形（角度题的主力） |
| `arc` | `c:[x,y], r, from, to` | 弧线 |
| `path` | `d:'M...'` | 任意路径 |
| `text` | `at:[x,y], text, size` | 文字 |

公共样式：`fill` `stroke` `sw`（线宽）`op`（透明度）`dash`。

### 让东西动起来（用 `upd`）

```js
{ id: 'wA', move: [dx, dy] }                    // 平移
{ id: 'wA', rot: -90, origin: [x, y] }          // 绕点旋转
{ id: 'wA', op: 0.2 }                           // 淡出
```

**关键**：`move` / `rot` 都是相对元素「原始坐标」的绝对量，不是增量。所以从 A 移到 B，再移到 C，第二次要写 B→C 的总偏移。

## 画布约定

- viewBox `0 0 900 520`
- 坐标系 y 轴向下（SVG 原生）
- **角度用数学惯例**：0° 朝右，逆时针增大。引擎内部已经翻转了 y，不用管

## 三条铁律

1. **每步只做一个动作。** 又要切、又要转、又要算，就拆成三步。
2. **每步都要有 `why`。** 只说「转一转」不够，要说「旋转不改变角的大小」。
3. **坐标和角度用代码算，不手填。** 现成的：

```js
ML.wedge(V, X, Y)   // 顶点 V 处，由 V→X、V→Y 张成的内角 { from, to, deg }
ML.angOf(V, X)      // V 看向 X 的方向角（度）
ML.pt(cx, cy, r, 角度)  // 极坐标取点
ML.round1(x)        // 保留一位小数
```

手填角度是所有几何动画对不齐的头号原因，一律用 `ML.wedge`。

## 播放器能力

- 上一步 / 下一步 / 空格播放暂停 / 方向键
- 4 档速度（0.6× ~ 2×）
- 步骤列表可点，任意跳转（**回退不做撤销栈，改成「清空 + 无声重放前 n 步 + 播放第 n 步」**，永远不会错乱）
- 音效开关，默认关，存在 localStorage
- 每道题的缩略图是自动渲染的**第一步**

## 部署

纯静态，没有构建步骤、没有外部依赖。现在跑在 **GitHub Pages**（仓库 `YBBCMG/math-lab`，`main` 分支根目录），推上去就自动重建。

```bash
node ../_push.mjs index.html js/lessons/新题目.js   # 按文件推（token 从 ../.gh_token 读，不落盘到仓库）
node ../_push_batch.mjs "feat: 加一道题" index.html js/lessons/新题目.js media --all-media
```

> 音频有 89 个，用 `_push.mjs` 会变成 89 次提交。**批量推送一律用 `_push_batch.mjs`**（走 Git Data API 的 blobs → tree → commit，一次提交推完）。

也可以丢到任何其他静态托管，例如 `surge ./ 你的域名.surge.sh`。

⭐ **不要用 ES module**（`type="module"`）。`file://` 直接双击打开时会被 CORS 拦成白屏。全部用普通 `<script>` + 全局变量。

## 本地预览与自检

```bash
node _serve.cjs          # http://127.0.0.1:8787  （只是本地预览，不是构建）
node _check.mjs          # 回归自检：几何断言 + 内容断言 + 交互断言
```

`_check.mjs` 会真的开一个 headless 浏览器（Playwright + 本机 Edge）跑完整流程，检查：

| 断言 | 判据 |
|---|---|
| 几何 | 撕角拼平角的三片角必须真的拼成半径 88 的半圆，覆盖 0°~180°，不能有角掉到直线下方 |
| 内容 | 每题 ≥2 种解法、每种 ≥8 步、每步都有「依据」和旁白、最后一步有可抄算式 |
| 交互 | 点步骤列表不能把整个文档滚走；任意跳转后元素数量与重放一致 |
| 控制台 | 全程 0 个 JS 报错 |

> 判几何**不能**用 `getBoundingClientRect` —— 它给的是「旋转后包围盒的包围盒」，会虚胖十几像素。必须沿路径 `getPointAtLength` 采样再换算回 viewBox。
